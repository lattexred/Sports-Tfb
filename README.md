## 📖 Overview
<a id="overview"></a>

**Sports TFB** is a dynamic dingbat font designed for sports-themed projects on Windows. With its unique collection of 93 distinct black silhouettes, this versatile font replaces standard alphanumeric characters, offering a total of 236 mapped characters. The **latest version** of Sports TFB enables graphic designers, marketers, and hobbyists to quickly integrate sports iconography directly into their documents without the need for separate image files. 

Distributed as a single TrueType (.ttf) file, **Sports TFB** is fully compatible with popular software like Microsoft Office and Adobe Creative Cloud. Users can easily manipulate size and alignment using standard typographic controls, making it an efficient choice for desktop designs.
